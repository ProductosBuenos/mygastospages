# 💰 Gestor Profesional de Gastos

Aplicación web para registrar, organizar y analizar gastos personales de forma sencilla.

## Características

* Registro de gastos con fecha, motivo, categoría y monto.
* Resumen automático de gastos.
* Cálculo del total gastado.
* Identificación de la categoría con mayor gasto.
* Historial completo de movimientos.
* Gráfico de gastos por categoría.
* Exportación de datos a CSV.
* Almacenamiento local mediante LocalStorage.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## Cómo utilizar

1. Descarga o clona este repositorio.
2. Abre el archivo `Gestor_Profesional_Gastos.html` en tu navegador.
3. Ingresa tus gastos y visualiza los resúmenes automáticamente.
